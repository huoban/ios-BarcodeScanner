
## 关键链路

1. `ScannerView.onAppear` 请求相机权限 → `BarcodeScanner.start()` 在串行队列配置 `AVCaptureSession`。
2. `AVCaptureMetadataOutput` 回调 → 水平角点过滤（可选）→ 控制字符过滤 → 字符串编码处理 → 连续 2 帧文本一致后通过 `@Published detected` 投递到主线程。
3. `ScannerView.handleDetected`：保存截图 → 写入 Core Data → 提示音/振动/自动复制 → 自动提交（`WKWebView`）或展示结果层。
4. 点击取景框外围或关闭子页面 → `setPaused(false)` 恢复扫描。
5. 设置变更通过 `scannerSignature` 触发 `restart()`，格式/摄像头/分辨率/编码即时生效。

## Android → iOS 对应

| Android | iOS |
|---|---|
| `DisplayModeActivity` | `ScannerView` |
| `SplashActivity` | `UILaunchScreen` + 运行时相机权限申请 |
| `CameraManager` | `BarcodeScanner`（AVFoundation） |
| `BarcodeScannerManager` | `BarcodeScanner` 的过滤/确认逻辑 + `BarcodeFormats` |
| `HistoryActivity` | `HistoryView` |
| `ImagePreviewActivity` / `TouchImageView` | `ZoomableImageView` |
| `SettingsFragment` / `preferences.xml` | `SettingsView` / `Preferences` |
| `AboutActivity` | `AboutView` |
| `WebViewActivity` | `WebViewScreen` |
| `AppDatabase` / `HistoryDao` / `HistoryEntity` | `PersistenceController` / `HistoryRecord` |
| `ImageSaver` | `ImageStore` |
| `SoundPlayer` / `Util` | `SoundPlayer` |
| `CsvExporter` | `CsvExporter` |
| `OkHttp` 远程查询 | `RemoteQuery` |

## 数据字段

`HistoryRecord`：id、barcodeType、barcodeFormat、resultText、isGS1、rawBytes、orientation、timestamp（毫秒）、imagePath。按 timestamp 倒序；删除 cutoff 为今天 0 点往前 N-1 天。

## 构建

`xcodegen generate` 从 `project.yml` 生成 `.xcodeproj`，`build_ipa.sh` 执行 `xcodebuild archive` 后将 `.app` 打包为 IPA。参见 [README.md](README.md)。
